## 📝 Project Scope

This is a project for our Programing Languages class at Texas A&M University-San Antonio. The following content is the scope of what is needed for the submission:

* The presentation will be 12 minutes long for a group of 2 students (08-10 minutes for the presentation + 02-04 minutes for the Q&A session).
* You can follow the provided presentation template (find it under Course Content > Week-16 > Project Presentation Template) or create your own, but make sure to include the following sections: Title page, Outline, Introduction, Methodology/Approach, Results/Demo, References, and Conclusion.
* Each student MUST submit the presentation in PPTX or PPT format from their own blackboard account, even if they are working in a group. An assignment titled "Project Presentation Submission" has been created for presentation submission inside the "Week-16" module.
* The presentation schedule will be announced after Sep 24th.
* Deadline for project presentation submission file(s): December 08, 2026, 11:59 p.m.

## AI Usage Statement

We thoughtfully disclose our use of LLMs. LLMs were used for (i) assisting in improving, debugging, and cleaning author-written code, with all changes verified before implementation; (ii) improving comments in the code to ensure proper readability; (iii) ensuring functionality across multiple machines (e.g., macOS, Linux, Windows); (iv) adjusting grammar and spelling wherever documentation is present; and (v) assisting in ensuring A* was implemented and used properly with verification. LLMs were not used for creating the game, picking the pathfinding, writing the rules for the game (i.e., how it functions, how the NPCs look and interact, how the play looks and interacts, etc.), defining the scope of the project, or other less-major tasks. No LLM output was implemented without verification by the authors.
