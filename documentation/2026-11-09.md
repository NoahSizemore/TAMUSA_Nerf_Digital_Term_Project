## Changes

* Noah wanted to improve compelxity in the pathfinding:
    * Noah changed `code/pathfinding.py`:
        * Graph (fixes 3, 5). `MOVES` now carries a per-direction step cost; `get_next_nodes()` stores (neighbour, cost) pairs with orthogonals at 1.0 and diagonals at sqrt(2), and rejects a diagonal unless both adjoining orthogonals are open, i.e., no more corner cutting. `walkable()` adds the bounds check the old code lacked, and `nearest_walkable()` snaps a tile that has ended up inside geometry back onto the graph, so no caller can KeyError.
        
        * Cost layer. `update_cost_layer()` rebuilds an additive dict[tile] -> extra cost each frame from two sources: crowding, where each NPC adds CROWD_COST to its own tile and CROWD_SPILL_COST to its 8-ring; and danger, a cone of half-angle DANGER_CONE down the player's facing, costed DANGER_COST at the player and falling linearly to zero at DANGER_RANGE. Costs are only ever ≥ 0, which is what keeps the heuristic admissible. Effect: the pack routes around a blocked corridor instead of being walled off by it (fix 4), and approaches drift toward your flanks rather than straight down your muzzle.
        
        * A*. `astar()` is heapq-based with a closed set, an ASTAR_MAX_EXPANSIONS safety cap, and the octile `heuristic()` (dx+dy) + (sqrt(2)−2)·min(dx,dy). Edge cost is step × (1 + cost_layer[next]). It returns the full path as a list of tiles after start, or None when genuinely unreachable — the old silent fallback to "the player's own tile" is gone (fix 2).

        * Flow field. `build_flow_field()` runs one Dijkstra expansion outward from the player over the cost layer, storing flow_field[tile] -> next tile toward player plus flow_dist[tile] -> cost to player. `flow_path()` walks it to produce a path in O(path length). `update()` refreshes the cost layer every frame and rebuilds the field when the player changes tile or FLOW_FIELD_REFRESH_MS elapses. flow_dist doubles as a reachability oracle via `flow_cost()`.
        
        * Line of sight and smoothing. `ray_clear()` is an Amanatides–Woo grid traversal that visits every tile a segment crosses. `line_of_sight()` wraps it with an optional body radius, testing the centre ray plus two perpendicular offset rays so a path can't clip a corner. `smooth_path()` does string pulling: scan the first PATH_SMOOTH_LOOKAHEAD waypoints furthest-first and drop everything before the first one you can see. The lookahead cap keeps it at one visibility test in the common case.
    * Noah changed `code/npc.py`:
        * See table 1 for more detail.
    * Noah made general changes to the difficulty of the game by reducing NPC speed to `0.01`.
        
### Table 1

| Method | Details |
|---|---|
|update_perception() | Sight is the existing raycast plus a sight_range limit. On a sighting it records last_known_pos, resets the memory timer, and picks ATTACK or CHASE on attack_dist. On losing sight it holds the last known position and goes to SEARCH until search_expire, then falls back to PATROL (or IDLE if no route).|
|alert() | Hearing. Gives an NPC within loudness tiles a position to investigate, but only promotes IDLE/PATROL NPCs so it never interrupts an active chase.|
|get_patrol_points() | Builds NPC_PATROL_POINTS waypoints within NPC_PATROL_RADIUS of the spawn, once, guarded by patrol_ready so a failure doesn't re-scan every frame.|
|current_goal() | Maps state to a target tile: player's tile when chasing, investigate_tile or last known position when searching, current waypoint when patrolling.|
|ensure_path() | The replacement for @lru_cache (fix 1). A path is reused while the goal is unchanged and younger than PATH_REFRESH_MS, and is re-smoothed each frame so it stays taut as the NPC moves. On a rebuild, a chasing NPC reads the shared flow field when its goal matches flow_goal, falling back to its own A*; searching and patrolling always use A*. On None, the path is cleared and a PATH_RETRY_MS cooldown prevents re-searching an unreachable goal every frame.|
|movement() | Follows self.path, popping a waypoint on arrival (within radius + 0.1) and calling on_goal_reached() when the path empties. If the next waypoint is occupied it reroutes and waits, but shoves past after NPC_STUCK_MS of no progress, which is the anti-deadlock. track_progress() only resets the stuck timer when the NPC actually covers ground.|
|on_goal_reached() | Advances the patrol index when patrolling; when searching, picks a fresh tile within NPC_SEARCH_RADIUS so the NPC sweeps the area instead of standing on your last known position.|
|check_wall_collision() | Rewritten as a proper axis-separated radius test (both corners of the leading edge), replacing int(self.x + dx * self.size), where size = 20 acted as an accidental 0.6-tile lookahead multiplier. This is what lets NPCs move at arbitrary angles after smoothing without clipping geometry.|
|run_logic() | Now a flat dispatch: dead → death animation; else raycast, update_perception(), then pain / attack / (chase|search|patrol → movement()) / idle.|
